# Sales Demo Mode

## 60초 데모
1. 고객 상세페이지 오픈
2. Source Code Assistant 클릭
3. `현재 페이지 진단`
4. 총점보다 Critical 3개 우선 설명
5. `AI View` 활성화
6. 실제 상세 이미지 위 `ALT 없음/파일명형 ALT` badge 시연
7. Schema 탭에서 Product/Offer 상태 확인
8. 개선 우선순위 3개로 마무리

## 권장 설명
- "사람 눈에는 정보가 충분하지만 HTML의 의미 데이터는 일부 비어 있습니다."
- "ALT는 이미지의 의미를 기계가 이해할 수 있게 전달하는 표준 HTML 정보 중 하나입니다."
- "공식 순위를 재현하는 것이 아니라 AI가 읽기 좋은 웹사이트 구조인지 진단합니다."

## 금지 설명
- "ALT가 없으면 AI는 이미지를 절대 못 봅니다."
- "ALT를 넣으면 네이버/ChatGPT 광고 순위가 올라갑니다."
- "이 점수는 네이버 AI 점수입니다."

## 기본 결과 우선순위
1. 고객이 눈으로 확인 가능한 문제
2. 수정 난이도가 낮은 문제
3. machine readability 직접 관련 문제
4. 개발팀 협업 필요 문제

Developer View는 필요할 때만 selector/HTML/rule id/snippet을 펼친다.
