# Source Notes

## 내부 기획자료에서 반영한 범위

### SearchTune OS / AutoBlog 제안서
- SEO/AEO/GEO를 구분해 진단하는 관점
- URL 진단 -> 개선 우선순위 구조
- 다크 네이비 + 블루 accent + 카드/score 중심의 디자인 언어
- 규칙 기반 평가와 AI 평가를 구분하는 구조

### Website AI Readiness / 광고 운영 기술제안서
- 사람이 보는 Website와 machine-readable layer의 차이
- ALT Missing / Empty / Generic / Duplicate 문제 유형
- Image Context + Page Context + Brand Context 관점
- crawl -> image collection -> ALT audit -> context/schema check -> implementation -> re-crawl 흐름
- ALT가 광고 순위 요소라고 단정하지 않는 주의사항
- Schema / ALT / Content 역할 구분
- Crawlability / Metadata / Content / Semantic Data / Consistency 프레임

## 구현 원칙
원본 PDF는 public repository에 업로드하지 않는다. 공개 가능한 요약과 제품 결정사항만 저장한다.
플랫폼 API/정책은 변경될 수 있으므로 구현 시 Chrome/OpenAI 등 공식 최신 문서를 다시 확인한다.
